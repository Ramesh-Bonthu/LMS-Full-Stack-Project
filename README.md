# Study Shine Joy - Professional AI-Powered LMS

Study Shine Joy (Lumen LMS) is a comprehensive, production-grade Learning Management System. It bridges the gap between traditional education and modern career preparation by integrating advanced AI modules directly into the learning workflow.

## 🏛️ System Architecture

The project is divided into three distinct specialized dashboards:

### 1. Student Dashboard (The Learning Hub)
*   **AI Mock Interviews**: Immersive video/voice sessions with resume analysis and adaptive difficulty.
*   **Course Enrollment**: Browse, search, and enroll in faculty-approved courses.
*   **Assignment Center**: Submit work (PDF) and track grading status.
*   **AI Quizzes**: Take smart assessments generated by faculty.
*   **Performance Tracking**: Visual analytics of grades and attendance.
*   **Interactive Content**: Access YouTube videos, PDFs, and links shared by faculty.

### 2. Faculty Dashboard (The Management Hub)
*   **Course Creation**: Design and manage course modules with video and document resources.
*   **AI Quiz Generator**: Instantly create MCQs on any topic using Groq AI.
*   **Assignment Grading**: Review student PDF submissions and provide feedback/marks.
*   **Student Tracking**: Monitor attendance and performance across your courses.
*   **Announcements**: Broadcast important updates to specific course groups.

### 3. Admin Dashboard (The Control Hub)
*   **User Management**: Approve or reject new signups (Faculty/Students).
*   **System Analytics**: Real-time stats on total users, courses, and system health.
*   **Enrollment Trends**: Track growth and activity across the platform.

## 🚀 Key AI Integrations

*   **Groq AI (Llama 3.1)**: Powers the Mock Interviewer and the Quiz Generator for near-instant responses.
*   **Speech Processing**: Real-time Speech-to-Text and Text-to-Speech for hands-free interviewing.
*   **Resume Extraction**: Automated PDF parsing to tailor interview questions to candidate experience.

## 🛠️ Technology Stack

| Layer | Technologies |
| :--- | :--- |
| **Frontend** | React 18, Vite, Tailwind CSS, Framer Motion, Lucide Icons |
| **Backend** | Node.js, Express.js, JWT Authentication |
| **Database** | PostgreSQL, Sequelize ORM |
| **AI/ML** | Groq SDK (Llama 3.1), Web Speech API |
| **File Handling** | Multer, PDF-Parse, File System Storage |

## 📦 Installation

### Prerequisites
*   Node.js (v18 or higher)
*   PostgreSQL Database

### Steps
1. **Clone the repository**
2. **Backend Setup**:
   ```bash
   cd lms-backend
   npm install
   # Configure .env (see Backend README for details)
   node server.js
   ```
3. **Frontend Setup**:
   ```bash
   cd study-shine-joy-main
   npm install
   npm run dev
   ```
